# Estructura de fotografías de CaminArte

Las fotografías definitivas de las fichas QR se organizarán por obra con nombres estables.

```
img/
└── obras/
    ├── el-cuervo/
    │   ├── principal.jpg
    │   ├── detalle-01.jpg
    │   └── detalle-02.jpg
    ├── pez-puntalarga/
    │   ├── principal.jpg
    │   └── detalle-01.jpg
    ├── el-lagar/
    │   ├── principal.jpg
    │   └── detalle-01.jpg
    ├── el-tamboril/
    │   ├── principal.jpg
    │   └── detalle-01.jpg
    ├── la-vieja/
    │   ├── principal.jpg
    │   └── detalle-01.jpg
    ├── el-pez-sierra/
    │   ├── principal.jpg
    │   └── detalle-01.jpg
    └── viejas-solteronas/
        ├── principal.jpg
        └── detalle-01.jpg
```

## Convención

- `principal.jpg`: fotografía principal o portada de la ficha.
- `detalle-01.jpg`, `detalle-02.jpg`, etc.: fotografías adicionales.
- Los nombres no deben cambiar al sustituir una fotografía.
- Al reemplazar una imagen manteniendo el mismo nombre, la URL de la ficha y la estructura HTML pueden mantenerse.
- Las fichas pueden dejar las fotografías desactivadas temporalmente hasta disponer de material definitivo.
